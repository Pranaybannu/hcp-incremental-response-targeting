Offline evidence is encouraging, not a rollout result.

On 800 test HCPs, top-20% uplift was 28.75 percentage points for the uplift ranking versus 5.25 for a pooled LR probability baseline. That evaluation baseline is unweighted; the current UI list uses the earlier balanced LR. These are different comparisons.

All results are synthetic. The test set was previously inspected. A prospective controlled pilot is needed.
