How reasons were generated and checked

ChatGPT authored a constrained factual language template for each available feature. The pipeline selects each HCP's two largest absolute local sensitivity drivers and inserts that HCP's verified values. Every sentence must match an approved template. This is LLM-assisted template generation, with deterministic per-HCP rendering. No separate per-HCP LLM API call was made.

A driver measures the change in predicted uplift when one feature is replaced by the training median. It is model sensitivity, not a causal explanation. Each selected fact and sensitivity is available below and in reason_audit.json. The action is a proposed rep review, not a clinical claim.

Held-out evaluation and uncertainty

The uplift model uses two outcome models, one per randomly assigned visit arm. Predicted uplift = P(outcome | visit, X) − P(outcome | no visit, X). Synthetic assignment is 50/50. The test set contains 800 HCPs, never used for fitting.

Cumulative gain is the cumulative sum of Y[T/0.5 − (1−T)/0.5], divided by test-set size. Qini area is the area between that curve and random ranking. This is an unnormalized, propensity-weighted area, not a library-normalized Qini score. Top-decile observed uplift is noisy; inspect arm counts and the bootstrap interval.

Rollout and measurement plan
Primary adoption metric: additional completed calls attributable to the recommendation per eligible flagged HCP, with deduplication against the rep's pre-existing plan. Track viewed → accepted → scheduled → completed, dismiss reasons, unavailable access, territory capacity, stale records, and list novelty. Opening the list alone is insufficient.
Randomize comparable rep-territory clusters to the existing or uplift list, balance baseline prescribing and capacity, freeze assignment, keep call budgets equal, and avoid cross-arm HCPs. Measure intention-to-treat incremental new prescribing per eligible HCP over a fixed four-week window and completed incremental calls per rep-week. Cluster-bootstrap intervals and report crossovers. This tests the new policy, not just those the reps chose to visit.
Six weeks: week 1 audit data, outcome and overlap, and interview reps; week 2 shadow lists and confirm feasibility; weeks 3–6 run a randomized pilot. Report adoption early and prescribing only for cohorts with mature four-week outcomes. Do not claim all week-6 outcomes are mature at renewal. No power calculation is possible without client variance, cluster counts and target minimum effect.
